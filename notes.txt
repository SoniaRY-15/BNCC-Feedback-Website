1) package.json 
- "start": menjalankan server production (mis. node server.js)
- "dev": menjalankan server development (mis. nodemon server.js)
- "build": bundling frontend bila ada (mis. webpack/parcel/vite)

2) server.js
Fungsi umum:
- Membuat instance server (mis. Express)
- Mengatur middleware (bodyParser/json, cors, static files)
- Men-serve folder `public`:
  - app.use(express.static(path.join(__dirname, 'public')));
- Men-setup routing API:
  - app.use('/api/feedback', feedbackRouter);
- Menangani error umum dan 404
- Menjalankan server di port dari process.env.PORT atau default 4000

Contoh alur:
- import express, path
- app.use(express.json())
- app.use(express.static(path.join(__dirname, 'public')))
- app.use('/api/*', routes)
- app.listen(PORT, () => console.log(`Server on ${PORT}`))

3) Routes / Controllers (backend)
- routes/feedback.js:
  - GET /api/feedback -> controller.getAllFeedback
  - POST /api/feedback -> controller.createFeedback
  - DELETE /api/feedback/:id -> controller.deleteFeedback (jika ada)
- controllers/feedbackController.js:
  - getAllFeedback(req, res): ambil data dari storage/db -> res.json(data)
  - createFeedback(req, res): validasi input -> simpan -> res.status(201).json(created)
  - Gunakan try/catch dan kirim response error yang jelas (status + pesan)

4) Storage: file / database
- Using file JSON:
  - path: data/feedback.json
  - Baca file dengan fs.readFileSync / fs.promises
  - Untuk menyimpan: fs.writeFileSync atau menggunakan library yang aman concurrent
  - Pastikan validasi sebelum menulis

5) public/index.html
- Struktur minimal:
  - <!DOCTYPE html>
  - <head> link ke css & meta </head>
  - <body> konten + <script src="/js/main.js"></script> </body>
- Pastikan script src mengarah ke file di folder public/js/

6) public/js/main.js (frontend logic)
- Contoh fungsi:
  - fetchFeedback() -> GET /api/feedback -> render ke DOM
  - submitForm(event) -> ambil input, POST ke /api/feedback, update UI
- Gunakan async/await dengan try/catch untuk error handling

7) Error handling & Logging
- Gunakan centralized error handler di Express:
  - app.use((err, req, res, next) => { console.error(err); res.status(500).json({ error: 'Internal Server Error' }) })
- Tambahkan validasi input endpoint untuk menghindari corrupt data.
- Untuk development gunakan logger seperti morgan.

8) Code snippets (backend - Express)
- GET /api/feedback:
  - async function getAllFeedback(req, res) {
      try {
        const data = await FeedbackModel.getAll();
        res.json(data);
      } catch (err) {
        res.status(500).json({ error: 'Gagal mengambil data' });
      }
    }

- POST /api/feedback:
  - async function createFeedback(req, res) {
      const { name, message, rating } = req.body;
      if (!name || !message) return res.status(400).json({ error: 'Field wajib belum diisi' });
      try {
        const newItem = await FeedbackModel.create({ name, message, rating });
        res.status(201).json(newItem);
      } catch (err) {
        res.status(500).json({ error: 'Gagal menyimpan data' });
      }
    }
